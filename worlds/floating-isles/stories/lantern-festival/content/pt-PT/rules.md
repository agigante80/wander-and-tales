# A Festa das Luzes Perdida: Regras para o Adulto

O Guia para o Adulto explica como o jogo funciona (os níveis, as estrelas de
energia, a ajuda, as surpresas, tudo isso). Esta página tem só o que é especial
nesta aventura. Uma jogada falhada nunca é uma derrota; ninguém perde.

## Preparar

- Não precisas de mapa impresso para esta. Imaginai a viagem da Praça das Lanternas
  até às nuvens, ou disponde três pontos pequenos para serem as três paragens.
- Cada jogador escolhe uma magia: Luz, Crescer, Transformação ou Voz. Duas magias
  diferentes resultam melhor, porque combiná-las é metade da diversão.
- Dá a cada jogador cinco estrelas de energia (cinco fichas ou peças pequenas).
  Gastam-se e voltam a encher-se durante o jogo.
- Constrói as coisas que vão surgindo (uma lanterna de papel, uma trepadeira, um
  ganchinho) com bocadinhos de casa e peças, à medida que avançam. Tudo pode ser
  qualquer coisa.
- Mantém os teus dados e a tabela de níveis de dados (no fim do kit) ao teu lado.

## A surpresa

Uma vez em cada paragem, os jogadores podem lançar para uma reviravolta; lê a linha
que sair. O Guia explica como funciona.

| Lança | Surpresa |
|---|---|
| 1 | Uma Borboleta Mensageira passa a esvoaçar e dá-vos uma dica grátis. |
| 2 | Apanhais uma faísca de luz quente: recuperai uma estrela de energia. |
| 3 | Uma brisa meiga e firme: o próximo desafio é Fácil. |
| 4 | O Gato de Névoa aparece e ronrona. Está tudo bem; continuai. |
| 5 | Uma lanterna amiga ilumina-vos o caminho: guardai uma jogada para usar mais tarde. |
| 6 | Uma cançãozinha de festa passa e toda a gente trauteia durante um turno feliz. |

## Como acaba

A festa não se ganha apanhando ninguém nem pondo nada certo à força. Quem juntou as
lanternas foi a Nimbo, uma baleia-nuvem bebé que estava sozinha e adorava demais as
luzes para as deixar ir. A aventura ganha-se quando as crianças oferecem à Nimbo a
sua amizade e um lugar na festa. Deixa isso assentar com calma; é o ponto inteiro.
Vê a página dos desafios para saber como conduzir o final, e para as soluções das
três paragens.
