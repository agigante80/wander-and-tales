# O Jardim Adormecido: Regras para o Adulto

O Guia para o Adulto explica como o jogo funciona (os níveis, as estrelas de
energia, a ajuda, as surpresas, tudo isso). Esta página tem só o que é especial
nesta aventura. Uma jogada falhada nunca é uma derrota; ninguém perde.

## Preparar

- Imprime o mapa. Cada jogador põe uma figura pequena (uma minifigura de peças de
  construção resulta bem) no Início.
- Cada jogador escolhe uma magia: Luz, Crescer, Transformação ou Voz. Duas magias
  diferentes resultam melhor, porque combiná-las é metade da diversão.
- Dá a cada jogador cinco estrelas de energia (cinco fichas ou peças pequenas).
  Gastam-se e voltam a encher-se durante o jogo.
- Constrói os objetos que vão surgindo (uma chave, uma flor, uma ponte) com
  bocadinhos de casa e peças, à medida que avançam. Tudo pode ser qualquer coisa.
- Mantém os teus dados e a tabela de níveis de dados (no fim do kit) ao teu lado.

## A surpresa

Uma vez em cada paragem, os jogadores podem lançar para uma reviravolta; lê a linha
que sair. O Guia explica como funciona.

| Lança | Surpresa |
|---|---|
| 1 | Uma Borboleta Mensageira passa a esvoaçar e dá-vos uma dica grátis. |
| 2 | Encontrais um brilho de energia: recuperai uma estrela de energia. |
| 3 | Uma brisa meiga: o próximo desafio é Fácil. |
| 4 | O Gato de Névoa aparece e ronrona. Está tudo bem; continuai. |
| 5 | Uma criatura sábia deixa-vos repetir uma jogada mais tarde, quando quiserdes. |
| 6 | Uma cançãozinha passa e toda a gente dança durante um turno feliz. |

## Como acaba

O Coração do Jardim não é uma batalha. O "antagonista" é o Duende Solitário, que
adormeceu o jardim só porque queria um amigo. A aventura ganha-se quando as crianças
lhe oferecem amizade. Deixa isso assentar com calma; é o ponto inteiro. Vê a página
dos desafios para saber como conduzir o coração, e para as soluções das três
paragens.
