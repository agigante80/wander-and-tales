# As Lanternas dos Pirilampos: Regras para o Adulto

*É a primeira vez? Lê primeiro o Guia para o Adulto. Explica a ideia toda em duas
páginas e nunca mais vais precisar dele.*

O Guia para o Adulto explica como funciona o jogo todo. Esta página tem só o que é
especial nesta história. Este é um conto suave, doce e quente do princípio ao fim, e
ninguém fica nunca assustado nem magoado. Uma jogada falhada nunca é uma derrota; ninguém
perde.

## Preparar tudo

- Imprime o mapa. Cada jogador põe uma figurinha no Início, a Aldeia das Lanternas.
- Este mundo não tem magia. Em vez disso, cada herói apoia-se numa de três qualidades:
  **Imaginação** (inventar ideias), **Coragem** (um coração firme) ou **Bondade** (cuidar
  dos outros). Na ficha do herói, onde diz magia, deixa cada criança escrever a qualidade
  de que mais gosta. Duas qualidades diferentes funcionam melhor juntas.
- Dá a cada jogador cinco estrelas de energia (cinco fichas ou peças pequenas). São
  gastas e recuperadas durante o jogo.
- Põe à mão três adereços, se puderes: um copo de papel ou qualquer coisa redonda para a
  lanterna de papel, um novelo de fio ou de lã vermelha para o fio vermelho, e qualquer
  ficha pequena para o bolo de arroz. Qualquer coisa pode ser qualquer coisa.
- Mantém os teus dados e a tabela de níveis dos dados, lá do fim do kit, ao teu lado.

## A Volta do Destino

Uma vez em cada paragem, os jogadores podem lançar o dado para uma volta; lê a linha que
corresponder. O Guia explica como funciona.

| Jogada | Volta do Destino |
|---|---|
| 1 | A Kon, a Raposa, sai do bambual e dá-vos uma dica grátis. |
| 2 | Reencontras a tua calma e recuperas uma estrela de energia. |
| 3 | Uma brisa suave desce a colina, e o próximo desafio é Fácil. |
| 4 | Os Cães-Leão Guardiões acenam com bondade desde o portão. Está tudo bem. |
| 5 | Uma pétala de cerejeira da sorte pousa no teu ombro: guarda uma jogada para usar mais tarde. |
| 6 | O toque suave de um sino de templo, e por um momento todos se sentem calmos e corajosos. |

## Como termina

O pirilampo mais tímido junto à Grande Lanterna é o último "desafio", mas não é nenhum
inimigo. É só um pequeno espírito que se sente acanhado demais para brilhar. O conto
ganha-se não por o empurrar, mas por o animar com uma palavra calma e bondosa, e a festa
irrompe em luz. Deixa a bondade fazer efeito; é esse o objetivo de tudo. Vê a página dos
enigmas para os três desafios e as suas soluções.
