# Landscape samples (gitignored)

This folder holds sample files (mostly PDFs) downloaded from other projects so we
could study their layout, reading levels, and format choices for the landscape
research. Only free, legally downloadable samples are kept here: publisher
quickstarts, free print-and-play releases, free previews, and open educational
resources.

**Everything in this folder except this README is gitignored.** We study these files
locally and never redistribute someone else's content. The findings drawn from them
live in the parent folder (`sample-teardowns.md` and `comparison-and-ideas.md`),
which cite each source by name and link so a reader can fetch the original
themselves.

If you are setting up fresh, this folder will be empty apart from this README; the
research notes stand on their own and link out to every source.
